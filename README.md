# danilobustos.com

Sitio personal de Danilo Bustos. Una plataforma de escritura, no un portafolio.

- **Stack:** [Astro](https://astro.build), Markdown/MDX, desplegado en Vercel.
- **Rutas:** `/` · `/writing` · `/writing/[slug]` · `/now` · `/about` · `/cv` · `/rss.xml`

## Desarrollo

```sh
npm install
npm run dev      # servidor local en http://localhost:4321
npm run build    # astro check + build estático en dist/
npm run preview  # sirve dist/ localmente
```

Requiere Node 22 o superior (ver `.nvmrc`).
