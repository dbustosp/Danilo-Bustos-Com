# Fuentes para las imágenes Open Graph

Satori necesita archivos TTF (no woff2), así que aquí viven instancias
estáticas de las dos familias del sitio, tomadas de Google Fonts:

- `Newsreader-500.ttf` — títulos.
- `Inter-400.ttf`, `Inter-500.ttf` — nombre y dominio.

Ambas bajo SIL Open Font License 1.1 (ver `LICENSE-*.txt`). Solo se usan
en build, para generar `/og/*.png`; no se sirven al navegador.
